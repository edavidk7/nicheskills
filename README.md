# nicheskills 💅

Install all:

```bash
npx skills add edavidk7/nicheskills
```

Install one:

```bash
npx skills add edavidk7/nicheskills --skill overleaf-link
```

## Skills

<!-- skills:start -->
### [gh](skills/gh)
MCP-less, user-verifiable, locally delegated GitHub integration for agents. Works through your own `gh` login, with no MCP server.

### [overleaf-link](skills/overleaf-link)
Read and edit Overleaf LaTeX projects through Overleaf's Git integration. Requires Overleaf Premium.
